# Day 11 – ROS 2 Python Package

## 1. What is a ROS 2 Python Package?

A ROS 2 Python package is a standard project structure used to organize Python nodes, dependencies, configuration files, and tests.

It allows us to build and run Python-based ROS 2 nodes in an organized way.

In this practical, the package contains:
- A Publisher node
- A Subscriber node
- Package configuration files
- Dependencies
- Test files
