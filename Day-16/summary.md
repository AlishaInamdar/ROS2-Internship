# Day 16 — ROS 2 Parameters Summary

## Objective

The objective of Day 16 was to understand ROS 2 Parameters, their purpose, architecture, commands, and implementation in Python.

## Work Completed

- Studied ROS 2 Parameters and their purpose.
- Created a Python ROS 2 package named `day16_parameters_package`.
- Created a parameter demonstration node.
- Declared three parameters:
  - `robot_name`
  - `speed`
  - `enabled`
- Built the package successfully using `colcon build`.
- Ran the parameter node successfully.
- Listed the node parameters using `ros2 param list`.
- Read parameter values using `ros2 param get`.
- Changed parameters at runtime using `ros2 param set`.
- Verified the updated parameter values.
- Captured screenshots of the implementation and results.
