# Day 1 – Ubuntu & ROS2 Installation

## Objective

The objective of Day 1 was to install Ubuntu using WSL2, install ROS2 Jazzy Desktop, understand the ROS2 architecture, create the first ROS2 workspace, develop a simple Python node, and explore RViz2.

## Topics Covered

- Ubuntu 24.04 LTS
- Windows Subsystem for Linux (WSL2)
- ROS2 Jazzy Desktop
- ROS2 Workspace
- colcon Build System
- ROS2 Python Package
- ROS2 Node
- RViz2

## Practical Tasks Completed

- Installed Ubuntu 24.04
- Installed ROS2 Jazzy Desktop
- Configured ROS2 Environment
- Created ROS2 Workspace
- Built Workspace using colcon
- Created First Python Package
- Executed First ROS2 Node
- Opened RViz2 Successfully
