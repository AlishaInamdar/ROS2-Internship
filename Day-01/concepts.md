# Concepts Learned

## Ubuntu

Linux-based operating system used for ROS2 development.

## WSL2

Allows Ubuntu to run inside Windows.

## ROS2

Robot Operating System used to develop robotics software.

## Node

Small executable program inside ROS2.

## Workspace

Directory where ROS2 packages are developed.

## Package

Collection of source code, configuration, and resources.

## colcon

ROS2 build tool.

## RViz2

Visualization software for robots and sensor data.
