# Linux Basics - Concepts

## Linux
Linux is an open-source operating system widely used in robotics, servers, cloud computing, and embedded systems.

## Why Linux for ROS 2?
ROS 2 is primarily developed and tested on Ubuntu Linux because it provides better compatibility, performance, and package management.

## Linux File System
- /home - User files
- /etc - Configuration files
- /bin - Essential commands
- /usr - Installed software
- /var - Log and variable data

## File Permissions
Linux controls access using:
- Read (r)
- Write (w)
- Execute (x)

## ROS 2 CLI
ROS 2 provides command-line tools to inspect packages, topics, nodes, services, and system status.

## Python in Linux
Python scripts can interact with the operating system to retrieve information such as the current user, working directory, and home directory.
