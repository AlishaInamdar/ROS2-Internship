# Commands Used

```bash
pwd
```
Displays the current working directory.

```bash
ls
```
Lists files and folders.

```bash
cd
```
Changes the current directory.

```bash
mkdir
```
Creates a new directory.

```bash
touch
```
Creates an empty file.

```bash
cp
```
Copies files or directories.

```bash
mv
```
Moves or renames files.

```bash
rm
```
Removes files or directories.

```bash
chmod
```
Changes file permissions.

```bash
ros2 --help
```
Displays available ROS 2 commands.

```bash
ros2 pkg list
```
Lists installed ROS 2 packages.

```bash
ros2 doctor
```
Checks the ROS 2 environment for configuration issues.

```bash
python3 system_info.py
```
Runs the Python example created during the practice session.
