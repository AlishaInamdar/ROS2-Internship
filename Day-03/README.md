## Objective
Understand the structure and purpose of a ROS 2 Workspace and learn how packages are built and executed.

## Topics Covered
- ROS 2 Workspace
- Workspace Structure
- Package Structure
- Colcon Build System
- Workspace Setup
- Running ROS 2 Packages

## Practical Tasks

- Inspected package structure
- Built the workspace using Colcon
- Sourced the workspace
- Executed an existing ROS 2 node
- Verified package installation
- Created a Python program to display workspace information

## Result
Successfully understood the ROS 2 Workspace structure and executed a ROS 2 package from the workspace.
