# Day 3 Summary

Today I learned the structure and purpose of a ROS 2 Workspace. I explored the workspace directories (src, build, install, and log), inspected the package structure, built the workspace using Colcon, sourced the workspace, and executed an existing ROS 2 node. I also verified the installed package and created a Python program to display workspace information. This activity improved my understanding of how ROS 2 manages packages inside a workspace.
