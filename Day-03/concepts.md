# ROS 2 Workspace Concepts

## ROS 2 Workspace
A ROS 2 Workspace is a directory used to develop, build, and manage ROS 2 packages.

## Workspace Structure

### src
Stores all ROS 2 source packages.

### build
Contains temporary build files generated by Colcon.

### install
Contains the installed packages that ROS 2 executes.

### log
Stores build logs and diagnostic information.

## Colcon
Colcon is the official build tool used to compile ROS 2 workspaces.

## Source Command
The command `source install/setup.bash` loads the workspace into the current terminal so ROS 2 can detect the packages.
