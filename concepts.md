# Concepts Learned

- A Node is the smallest executable unit in ROS 2.
- Nodes communicate using Topics, Services, and Actions.
- A Publisher sends data, while a Subscriber receives data.
- The Talker node publishes messages to the `/chatter` topic.
- The Listener node subscribes to the `/chatter` topic and displays received messages.
- The `ros2 node` command is used to inspect running nodes.
